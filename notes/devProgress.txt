20260116 - chat gpt recommende3d filerign and case/controls count
Recommended minimums (rule of thumb)
Use case	Minimum controls
Classical ML	≥ 500
Deep learning	≥ 1,000
Perturb-seq / GEARS	5–20% of dataset
Cell-type–specific controls	≥ 200 per cell type


nFeature_guide == 1
AND
nCount_guide ≤ 10–20


| Situation                    | Use this                                   |
| ---------------------------- | ------------------------------------------ |
| Control guides exist         | `feature_call` / `gene`                    |
| No control guides            | `nFeature_guide == 1` + low `nCount_guide` |
| Downstream DE / GNN training | Use **explicit controls only**             |
